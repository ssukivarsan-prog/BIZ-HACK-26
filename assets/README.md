# assets/

Place your static assets in these subdirectories.
They are declared in `pubspec.yaml` and bundled into the app at build time.

## assets/images/
- `logo.png`           — FreshVeg brand logo (1024×1024 recommended)
- `logo_white.png`     — White version for dark backgrounds
- `placeholder_veg.png`— Default image shown when no vegetable photo is set
- `onboarding_1.png`   — (optional) Onboarding illustration 1
- `onboarding_2.png`   — (optional) Onboarding illustration 2

## assets/icons/
- `ic_tomato.svg`      — Example vegetable category icon
- `ic_leafy.svg`
- `ic_root.svg`
- `ic_gourds.svg`
- `ic_beans.svg`
- `ic_herbs.svg`

## assets/animations/
Lottie JSON animation files used across the app:
- `loading.json`       — General loading animation
- `success.json`       — Order placed / success animation
- `empty_cart.json`    — Shown on empty cart screen
- `empty_orders.json`  — Shown on empty orders screen
- `delivery.json`      — Shown on order tracking screen

Free Lottie animations: https://lottiefiles.com
Recommended search terms: "vegetables", "delivery truck", "success checkmark", "empty box"
